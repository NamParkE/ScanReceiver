# ScanReceiver

복합기·네트워크 스캐너의 **"Scan to FTP"(FTP로 스캔 전송)** 기능으로 보낸 파일을 이 PC에서 받는 Win32 GUI 프로그램입니다. 별도 FTP 서버 설치 없이 실행 파일 하나로 동작합니다.

## 기능

- FTP 수신 서버 (Passive/Active 모두 지원, `STOR` `APPE` `STOU` `MKD` `CWD` `LIST` `RNFR/RNTO` `DELE` 등)
- 한글 파일명: 스캐너가 UTF-8로 보내든 CP949로 보내든 자동 판별
- Windows 11(Fluent) 스타일의 작은 메인 창: 상태 칩(마우스를 올리면 스캐너 설정값), 설정 카드, 토글 스위치
- **받은 파일** 창: 창이 열려 있을 때 파일을 받으면 자동으로 뜸 (더블클릭: 열기, 우클릭: 폴더에서 보기)
- **로그** 창: 버튼으로 열기, FTP 명령까지 자세히 보기 선택
- 트레이: 닫기·최소화 시 트레이로 숨고 계속 수신, 트레이에 있을 때 파일을 받으면 2초 토스트 알림
- 설정은 실행 파일 옆 `ScanReceiver.ini`에 저장
- 보안: 저장 폴더 밖 접근 차단, FTP bounce 차단, 데이터 연결은 제어 연결과 같은 IP만 허용, 로그인 3회 실패 시 연결 끊기

## 빌드

Visual Studio(또는 Build Tools, "C++를 사용한 데스크톱 개발" 워크로드):

```bat
build.bat
```

MinGW-w64 (w64devkit, MSYS2 등):

```bat
build_mingw.bat
```

CMake도 사용할 수 있습니다 (`CMakeLists.txt`). 결과물: `build\ScanReceiver.exe`

## 사용법

1. `ScanReceiver.exe` 실행 → 저장 폴더, 사용자/비밀번호 설정 → **서버 시작**
2. 처음 시작할 때 Windows 방화벽 창이 뜨면 **개인 네트워크 허용**
   - 창이 안 뜨거나 거부했다면 방화벽에서 `ScanReceiver.exe`를 허용 목록에 추가하세요 (포트 21과 패시브 포트 범위 50000~50100).
3. 스캐너(복합기) 웹 관리 페이지 또는 패널의 주소록/FTP 전송 설정에 입력:

   | 항목 | 값 |
   | --- | --- |
   | 서버 주소 / 호스트 | 화면 상태줄에 표시되는 PC IP (예: `192.168.0.10`) |
   | 포트 | `21` (변경했다면 그 값) |
   | 사용자 / 비밀번호 | 프로그램에 설정한 값 |
   | 경로 / 폴더 | 비워두거나 `/` (하위 폴더를 쓰려면 `/스캔` 처럼 입력, 미리 만들어 두거나 스캐너가 MKD로 생성) |
   | 전송 모드 | Passive 권장 |

4. 스캐너의 "연결 테스트"를 누르면 **로그** 창에 접속 기록이 표시됩니다.
5. 창을 닫아도 트레이에서 계속 받습니다. 완전히 끄려면 트레이 아이콘 우클릭 → **종료**.

## 문제 해결

| 증상 | 확인할 것 |
| --- | --- |
| 포트 사용 중 오류 | IIS FTP, FileZilla Server 등이 21번을 쓰는지 확인하거나 포트를 2121 등으로 바꾸고 스캐너도 같이 변경 |
| 로그 창에 아무것도 안 뜸 | 방화벽 허용, PC와 스캐너가 같은 네트워크인지, IP를 정확히 입력했는지 |
| 로그인은 되는데 전송 실패 (425) | 방화벽에서 패시브 포트 범위가 막혀 있음 → 프로그램 자체를 허용하거나 스캐너를 Active 모드로 |
| 한글 파일명이 깨짐 | 로그에 찍힌 원본 이름을 확인해 주세요 (UTF-8/CP949 외 인코딩일 수 있음) |

## 참고

- 비밀번호는 `ScanReceiver.ini`에 평문으로 저장됩니다. FTP 자체도 암호화되지 않으므로 사내/가정 LAN에서만 사용하세요.
- IPv4만 지원합니다.
